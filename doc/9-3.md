# Ready for training

## Check the dataset files

Place these three files in your working folder:

- `train.iob`: training data;
- `dev.iob`: development data for selecting the best checkpoint;
- `test.iob`: held-out data for final evaluation.

Each line contains one sentence. Tokens are separated by spaces, and each token is connected to its label with `|`:

```text
But|O I|O 'm|O get|I-INTRAN_RES used|O to|O it|O already|O
So|O I|O grow|I-INTRAN_RES up|O about|O approximately|O Saitama|O .|O
And|O we|O packed|I-INTRAN_RES up|O .|O
```

We will preserve these existing splits.

Create a Python file named `train_tagger.py` in the same folder. Add the following Python blocks to that file in order.

## Read the datasets

Import `Path`:

```python
from pathlib import Path
```

Define a function that reads the `token|label` format:

```python
def read_dataset(file_path):
    rows = []

    for line_number, line in enumerate(
        Path(file_path).read_text(
            encoding="utf-8-sig"
        ).splitlines(),
        start=1,
    ):
        line = line.strip()

        if not line:
            continue

        tokens = []
        tags = []

        for item in line.split():
            if "|" not in item:
                raise ValueError(
                    f"{file_path}, line {line_number}: "
                    f"missing | in {item!r}"
                )

            token, tag = item.rsplit("|", 1)

            if not token or not tag or tag.endswith("-"):
                raise ValueError(
                    f"{file_path}, line {line_number}: "
                    f"invalid annotation {item!r}"
                )

            tokens.append(token)
            tags.append(tag)

        rows.append({
            "tokens": tokens,
            "tags": tags,
        })

    if not rows:
        raise ValueError(f"{file_path} is empty.")

    return rows
```

Load all three files:

```python
train_rows = read_dataset("train.iob")
dev_rows = read_dataset("dev.iob")
test_rows = read_dataset("test.iob")
```

Check the number of sentences and inspect the first training example:

```python
print("Training sentences:", len(train_rows))
print("Development sentences:", len(dev_rows))
print("Test sentences:", len(test_rows))

print(train_rows[0])
```

## Create the label mappings

Collect the unique labels from the training data:

```python
label_list = sorted({
    tag
    for row in train_rows
    for tag in row["tags"]
})
```

Create mappings between labels and numeric IDs:

```python
label2id = {
    label: index
    for index, label in enumerate(label_list)
}

id2label = {
    index: label
    for label, index in label2id.items()
}

print(label2id)
```

Check that the development and test sets use labels included in the training label inventory:

```python
for split_name, split_rows in [
    ("dev", dev_rows),
    ("test", test_rows),
]:
    unknown_labels = {
        tag
        for row in split_rows
        for tag in row["tags"]
        if tag not in label2id
    }

    if unknown_labels:
        raise ValueError(
            f"{split_name} contains labels absent from training: "
            f"{sorted(unknown_labels)}"
        )
```

**Note.** If this check fails, review the dataset's official tag inventory and label consistency. Do not move development or test examples into the training set to resolve the error.

## Organize the existing splits

Import `Dataset` and `DatasetDict`:

```python
from datasets import Dataset, DatasetDict
```

Create one dataset containing the three predefined splits:

```python
dataset = DatasetDict({
    "train": Dataset.from_list(train_rows),
    "dev": Dataset.from_list(dev_rows),
    "test": Dataset.from_list(test_rows),
})

print(dataset)
```

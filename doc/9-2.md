# Install the packages

*Note1. Reminder: I might encourage you to make a new virtual environment for a new project. If you don't remember how to do this, please check [here](1-4.html).*

*Note2. Reminder: Installing packages should be done in your terminal, NOT in your python script.*

Run the following command in a terminal or command prompt:

```bash
python -m pip install torch transformers datasets accelerate scikit-learn
```

*Note3. If you are using Google Colab, run this command in a notebook code cell instead:*
```python
!pip install torch transformers datasets accelerate scikit-learn
```

We will use:

- `transformers` to load and train a pretrained language model;
- `datasets` to organize the training data;
- `torch` to run the model;
- `accelerate` to support the training process;
- `scikit-learn` to calculate evaluation scores.

*Note4.* Training can run on a CPU, but a GPU will usually make it faster. The first model download requires an internet connection.*

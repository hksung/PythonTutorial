# Install the packages

Run the following command in a terminal or command prompt:

```bash
python -m pip install torch transformers datasets accelerate scikit-learn
```

We will use:

- `transformers` to load and train a pretrained language model;
- `datasets` to organize the training data;
- `torch` to run the model;
- `accelerate` to support the training process;
- `scikit-learn` to calculate evaluation scores.

**Note.** Training can run on a CPU, but a GPU will usually make it faster. The first model download requires an internet connection.

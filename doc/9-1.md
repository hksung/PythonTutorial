# Dataset

In this tutorial, we will train a model to identify **argument structure constructions (ASCs)** in English sentences by assigning construction labels to verbs. Other tokens receive the label `O`.

We will use data from the [ASC Treebank](https://github.com/LCR-ADS-Lab/ASC-Treebank), specifically the dataset used in Sung and Kyle’s (2024) study, [*Leveraging pre-trained language models for linguistic analysis: A case of argument structure constructions*](https://aclanthology.org/2024.emnlp-main.415/). 

For this tutorial, the data have already been converted into a simple format: each line contains one sentence, and each word is followed by `|` and its label. 

```text
And|O we|O packed|I-INTRAN_RES up|O .|O
After|O all|O this|O problems|O I|O became|I-INTRAN_RES dissappointed|O .|O
```

Download <a href="{{ site.baseurl }}/corpus/asc-io.zip" download="asc-io.zip">asc-io.zip</a>. It contains `train.iob`, `dev.iob`, and `test.iob` (the `.iob` extension is only a file name; the labels follow the IO scheme described below).

The dataset uses an IO tagging scheme: verbs receive an ASC label prefixed with I-, while all other tokens receive O. Each token and its label are separated by |. The model will learn to predict labels such as `I-INTRAN_RES` and `I-TRAN_S`, as well as `O` for tokens without an ASC label. The original spelling and grammatical errors are preserved.

This task is called **token classification**: the model predicts a label for each token rather than constructing a syntactic tree.

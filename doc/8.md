## Lexicogrammatical feature annotation

- Build a shared annotation guidelines: <a href="https://docs.google.com/document/d/1F7vsgnrHRCnNOxVz8t6jCgu2gBDfysjB6mksJplEtDs/edit?usp=sharing" target="_blank" rel="noopener noreferrer">Shared GoogleDoc</a>
- The example sentences are from Biber et al. (2007), *Longman Grammar of Spoken and Written English*. 
- This exercise replicates the annotation activity from the [AACL 2024 workshop](https://github.com/hksung/AACL24-Workshop).
- Process:
   1. Download the sample text for your group's feature.
   2. Open the downloaded `.txt` file in VSCode, plain-text editor, or a spreadsheet. 
   3. Identify each instance of the feature and add the tag to the position specified in that feature's description (Please check the shared GoogleDoc!).

## Task

- A shared annotation guidelines: <a href="https://docs.google.com/document/d/1F7vsgnrHRCnNOxVz8t6jCgu2gBDfysjB6mksJplEtDs/edit?usp=sharing" target="_blank" rel="noopener noreferrer">Shared GoogleDoc</a>

- Process:
   1. Check the minimal guides/examples on the shared annotation guidelines.
   2. Download the sample text for your group's feature.
   3. Open the downloaded `.txt` file in VSCode, plain-text editor, or a spreadsheet. 
   4. Identify each instance of the feature.
   5. Add the tag to the position specified in that feature's description.
   6. Document on the annotation guildelines, while working on the annotation.

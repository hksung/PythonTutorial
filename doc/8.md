## Annotation task

- A shared annotation guidelines: <a href="https://docs.google.com/document/d/1F7vsgnrHRCnNOxVz8t6jCgu2gBDfysjB6mksJplEtDs/edit?usp=sharing" target="_blank" rel="noopener noreferrer">Shared GoogleDoc</a>
- Process:
   1. Download the sample text for your group's feature.
   2. Open the downloaded `.txt` file in VSCode, plain-text editor, or a spreadsheet. 
   3. Identify each instance of the feature.
   4. Add the tag to the position specified in that feature's description (Check the minimal guides on the guidelines).
   5. Document on the annotation guildelines

# English POS tagging with spaCy

## (Review) Installing spaCy and the English pipeline

Install spaCy from a terminal or command prompt:

```bash
pip install -U spacy
```

Then download the English transformer pipeline:

```bash
python -m spacy download en_core_web_trf
```

In Google Colab, add `!` before each command:

```python
!pip install -U spacy
!python -m spacy download en_core_web_trf
```

The transformer pipeline is relatively large. A smaller pipeline can be used when memory or processing time is limited:

```bash
python -m spacy download en_core_web_sm
```

The code in this tutorial uses `en_core_web_trf`, but the same attributes are available in `en_core_web_sm`.

## Loading the pipeline

Import spaCy and load the pipeline:

```python
import spacy

nlp_en = spacy.load("en_core_web_trf")
```

Inspect the installed spaCy version and pipeline information:

```python
print("spaCy version:", spacy.__version__)
print("Pipeline name:", nlp_en.meta.get("name"))
print("Pipeline version:", nlp_en.meta.get("version"))
print("Components:", nlp_en.pipe_names)
```

Recording versions is important because NLP predictions may differ across package or model versions.

## Processing an English sentence

Create an English text:

```python
english_text = (
    "The students were carefully writing "
    "their final research papers."
)
```

Process the text with the pipeline:

```python
english_doc = nlp_en(english_text)
```

The output is a spaCy `Doc` object. The `Doc` contains a sequence of `Token` objects.

```python
print(type(english_doc))
print(type(english_doc[0]))
```

You can print the tokenized text with a loop:

```python
for token in english_doc:
    print(token.text)
```

## Inspecting part-of-speech annotations

Each `Token` stores multiple linguistic annotations:

```python
for token in english_doc:
    print(
        token.text,
        token.lemma_,
        token.pos_,
        token.tag_,
        token.morph,
        sep="\t"
    )
```

The attributes have the following meanings:

- `token.text`: the original token form;
- `token.lemma_`: the lemma assigned to the token;
- `token.pos_`: the coarse-grained Universal POS category;
- `token.tag_`: a more detailed English part-of-speech tag;
- `token.morph`: morphological features predicted for the token.

For example, an output may associate *writing* with:

```text
text:   writing
lemma:  write
UPOS:   VERB
tag:    VBG
```

The exact output should always be checked with the installed pipeline rather than assumed in advance.

## Printing a readable analysis table

Use formatted strings to align the output:

```python
print(
    f"{'TOKEN':<15}"
    f"{'LEMMA':<15}"
    f"{'UPOS':<10}"
    f"{'TAG':<10}"
    f"{'MORPH'}"
)

for token in english_doc:
    print(
        f"{token.text:<15}"
        f"{token.lemma_:<15}"
        f"{token.pos_:<10}"
        f"{token.tag_:<10}"
        f"{token.morph}"
    )
```

A punctuation mark is also represented as a token. Its universal category is normally `PUNCT`.

## Universal and English-specific tags

Consider the following forms:

```text
write
writes
wrote
writing
written
```

They may all be assigned the universal category `VERB`, but their detailed English tags can distinguish base, present-tense, past-tense, and participial forms.

Process the forms in context:

```python
verb_text = (
    "I write every day. "
    "She writes every day. "
    "They wrote yesterday. "
    "We are writing now. "
    "The report was written yesterday."
)

verb_doc = nlp_en(verb_text)

for token in verb_doc:
    if token.lemma_ == "write":
        print(
            token.text,
            token.lemma_,
            token.pos_,
            token.tag_,
            token.morph,
            sep="\t"
        )
```

The universal tag gives a broad grammatical category. The detailed tag and morphological features provide additional information about the form.

## Context-sensitive tagging

Part-of-speech tagging is contextual. Consider the word *record*:

```python
context_text = "Researchers record speech and examine each record."
context_doc = nlp_en(context_text)

for token in context_doc:
    if token.text.lower() == "record":
        print(
            token.text,
            token.lemma_,
            token.pos_,
            token.tag_,
            sep="\t"
        )
```

The two occurrences have the same spelling but different grammatical functions. The first functions as a verb, while the second functions as a noun.

Try another ambiguous form:

```python
saw_doc = nlp_en("I saw a saw.")

for token in saw_doc:
    print(
        token.text,
        token.lemma_,
        token.pos_,
        token.tag_,
        sep="\t"
    )
```

Inspect whether the two occurrences receive different lemmas and part-of-speech tags.

## Excluding punctuation and spaces

Many analyses exclude punctuation and space tokens:

```python
for token in english_doc:
    if not token.is_space and not token.is_punct:
        print(token.text, token.pos_)
```

The conditions mean:

```text
not token.is_space  → keep tokens that are not spaces
not token.is_punct  → keep tokens that are not punctuation
```

This filtering step does not yet remove function words. It only removes spaces and punctuation.

## Extracting nouns

Extract the lemmas of all common nouns:

```python
english_nouns = [
    token.lemma_.lower()
    for token in english_doc
    if token.pos_ == "NOUN"
]

print(english_nouns)
```

This excludes proper nouns because spaCy normally assigns them the UPOS category `PROPN`.

To include both common and proper nouns:

```python
english_nouns_and_names = [
    token.lemma_.lower()
    for token in english_doc
    if token.pos_ in {"NOUN", "PROPN"}
]

print(english_nouns_and_names)
```

Whether proper nouns should be included depends on the research question.

## Extracting verbs

Extract lexical verbs:

```python
english_verbs = [
    token.lemma_.lower()
    for token in english_doc
    if token.pos_ == "VERB"
]

print(english_verbs)
```

Auxiliaries are normally represented separately with the UPOS category `AUX`:

```python
english_auxiliaries = [
    token.lemma_.lower()
    for token in english_doc
    if token.pos_ == "AUX"
]

print(english_auxiliaries)
```

This distinction matters for lexical-diversity analysis. A study that intends to count lexical verbs may include `VERB` but exclude `AUX`.

english_adjectives = [

english_adverbs = [

## Counting part-of-speech categories

Use `Counter` to calculate the frequency of each UPOS category:

```python
from collections import Counter

english_pos_counts = Counter(
    token.pos_
    for token in english_doc
    if not token.is_space and not token.is_punct
)

print(english_pos_counts)
```

To display the categories from most to least frequent:

```python
for pos, frequency in english_pos_counts.most_common():
    print(pos, frequency)
```

## Creating a reusable inspection function

Define a function that prints the main annotations for any English text:

```python
def inspect_spacy_text(text, nlp):
    doc = nlp(text)

    print(
        f"{'TOKEN':<15}"
        f"{'LEMMA':<15}"
        f"{'UPOS':<10}"
        f"{'TAG':<10}"
        f"{'MORPH'}"
    )

    for token in doc:
        if not token.is_space:
            print(
                f"{token.text:<15}"
                f"{token.lemma_:<15}"
                f"{token.pos_:<10}"
                f"{token.tag_:<10}"
                f"{token.morph}"
            )

    return doc
```

Apply the function:

```python
new_doc = inspect_spacy_text(
    "Language learners frequently use familiar words.",
    nlp_en
)
```

Returning the `Doc` allows the processed text to be reused in later code.

## Processing multiple texts efficiently

For a collection of texts, spaCy's `nlp.pipe()` method is generally more efficient than calling the pipeline separately for every text.

```python
english_texts = [
    "The first student revised the essay.",
    "The second student added several examples.",
    "The third student explained the argument clearly."
]

for doc in nlp_en.pipe(english_texts):
    lemmas = [
        token.lemma_.lower()
        for token in doc
        if not token.is_space and not token.is_punct
    ]

    print(lemmas)
```

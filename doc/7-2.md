## Process all text files

Read each `.txt` file and process the texts using `nlp_en.pipe()`:

```python
texts = [
    text_file.read_text(encoding="utf-8")
    for text_file in text_files
]

docs = list(nlp_en.pipe(texts))
```

## Collect token-level POS annotations

For the frequency analysis, create another DataFrame that excludes spaces and punctuation:

```python
token_annotations = []

for text_file, doc in zip(text_files, docs):
    for token in doc:
        if not token.is_space and not token.is_punct:
            token_annotations.append(
                {
                    "file": text_file.name,
                    "token": token.text,
                    "lemma": token.lemma_,
                    "upos": token.pos_,
                    "xpos": token.tag_,
                }
            )

print(f"Number of token annotations: {len(token_annotations)}")
print(token_annotations[:5]) # for preview
```

The resulting table contains the following columns:

* `file`: the source filename;
* `token`: the original word or punctuation mark;
* `lemma`: the base form of the token;
* `upos`: the universal POS tag;
* `xpos`: the detailed English POS tag.


```python
anno_df = pd.DataFrame(token_annotations) #save into dataframe
print(anno_df.head())
```

## Count UPOS tags in each text

Group the data by filename and UPOS tag:

```python
upos_counts = (
    anno_df
    .groupby(["file", "upos"])
    .size()
    .reset_index(name="count")
)

print(upos_counts.head())
```

## Normalize UPOS frequencies

Now calculate the normalized frequency of each UPOS tag to account for differences in text length. As we practiced in an earlier module, we will normalize frequencies per 1,000 tokens.

The normalized frequency is calculated as:

**Normalized frequency** = (Raw frequency / Total number of tokens in the text) × 1,000

First, define a function that calculates normalized frequency:

```python
def normalize_frequency(count, total_tokens, base=1000):
    return (count / total_tokens) * base
```

Next, calculate the total number of tokens in each text and apply the function to the UPOS counts:

```python
token_totals = anno_df.groupby("file").size() # count the total number of tokens in a text

upos_counts["normalized_freq"] = upos_counts.apply(
    lambda row: normalize_frequency(
        row["count"],
        token_totals[row["file"]] ),
    axis=1
) # add normalized frequency counts

print(upos_counts.head()) # check
```

The resulting DataFrame contains both raw counts (`count`) and normalized frequencies (`normalized_freq`) for each UPOS tag in each text.

# Evaluation

## Evaluate the trained model

In this tutorial, we will evaluate the saved ASC tagger on `test.iob`.

The test set is used to measure performance on held-out examples. Do not use its results to choose hyperparameters or training checkpoints.

Create a new Python file named `evaluate_tagger.py` in the same folder as `test.iob` and the `asc_tagger` folder.

## Import the packages

```python
from pathlib import Path

import numpy as np
from datasets import Dataset
from sklearn.metrics import accuracy_score, classification_report
from transformers import (
    AutoTokenizer,
    AutoModelForTokenClassification,
    DataCollatorForTokenClassification,
    Trainer,
    TrainingArguments,
)
```

## Load the trained model

Load the tokenizer and model saved during training:

```python
tokenizer = AutoTokenizer.from_pretrained("asc_tagger")

model = AutoModelForTokenClassification.from_pretrained(
    "asc_tagger"
)

label2id = model.config.label2id
id2label = model.config.id2label
```

Use the saved label mappings so that label IDs match those used during training.

## Read the test dataset

The test file uses the same format as the training data: one sentence per line, with each token connected to its label by `|`.

```python
def read_dataset(file_path):
    rows = []

    for line_number, line in enumerate(
        Path(file_path).read_text(
            encoding="utf-8-sig"
        ).splitlines(),
        start=1,
    ):
        line = line.strip()

        if not line:
            continue

        tokens = []
        tags = []

        for item in line.split():
            if "|" not in item:
                raise ValueError(
                    f"{file_path}, line {line_number}: "
                    f"missing | in {item!r}"
                )

            token, tag = item.rsplit("|", 1)

            if not token or tag not in label2id:
                raise ValueError(
                    f"{file_path}, line {line_number}: "
                    f"invalid token or unknown label in {item!r}"
                )

            tokens.append(token)
            tags.append(tag)

        rows.append({
            "tokens": tokens,
            "tags": tags,
        })

    if not rows:
        raise ValueError(f"{file_path} is empty.")

    return rows
```

Load the test sentences:

```python
test_rows = read_dataset("test.iob")
test_dataset = Dataset.from_list(test_rows)

print("Test sentences:", len(test_rows))
```

## Tokenize the test data

As in training, assign the word-level label to the first model token of each word. Ignore additional pieces and special tokens by assigning `-100`.

Here, we check for examples that exceed the model's length limit rather than silently omitting words from evaluation.

```python
def tokenize_and_align_labels(batch):
    encoded = tokenizer(
        batch["tokens"],
        is_split_into_words=True,
        truncation=False,
    )

    max_length = model.config.max_position_embeddings

    if any(
        len(input_ids) > max_length
        for input_ids in encoded["input_ids"]
    ):
        raise ValueError(
            "A test sentence exceeds the model's length limit. "
            "Split long sentences into shorter labeled sequences "
            "before evaluation."
        )

    all_labels = []

    for sentence_index, tags in enumerate(batch["tags"]):
        word_ids = encoded.word_ids(
            batch_index=sentence_index
        )

        aligned_labels = []
        previous_word_id = None

        for word_id in word_ids:
            if word_id is None or word_id == previous_word_id:
                aligned_labels.append(-100)
            else:
                aligned_labels.append(
                    label2id[tags[word_id]]
                )

            previous_word_id = word_id

        all_labels.append(aligned_labels)

    encoded["labels"] = all_labels
    return encoded
```

Apply the function:

```python
tokenized_test = test_dataset.map(
    tokenize_and_align_labels,
    batched=True,
    remove_columns=["tokens", "tags"],
)
```

## Configure prediction

Create a data collator to pad examples within each batch:

```python
data_collator = DataCollatorForTokenClassification(
    tokenizer=tokenizer
)
```

Configure the trainer for prediction:

```python
evaluation_args = TrainingArguments(
    output_dir="evaluation_results",
    per_device_eval_batch_size=8,
    report_to="none",
    dataloader_num_workers=0,
)

trainer = Trainer(
    model=model,
    args=evaluation_args,
    processing_class=tokenizer,
    data_collator=data_collator,
)
```

This trainer will generate predictions without updating the model.

## Generate predictions and calculate scores

We will report:

- **Accuracy:** the proportion of correctly labeled tokens, including `O`;
- **Precision:** how often a predicted ASC label is correct;
- **Recall:** how often the model identifies a gold-standard ASC label;
- **F1:** the harmonic mean of precision and recall;
- **Support:** the number of gold-standard examples for each label.

Add the following block at the end of `evaluate_tagger.py`:

```python
if __name__ == "__main__":
    prediction_output = trainer.predict(tokenized_test)

    predicted_ids = np.argmax(
        prediction_output.predictions,
        axis=-1,
    )
    gold_ids = prediction_output.label_ids

    # Keep only the first model token of each original word.
    mask = gold_ids != -100

    gold_labels = gold_ids[mask]
    predicted_labels = predicted_ids[mask]

    accuracy = accuracy_score(
        gold_labels,
        predicted_labels,
    )

    # Report ASC categories separately from O.
    asc_label_ids = [
        label_id
        for label_id in sorted(id2label)
        if id2label[label_id] != "O"
    ]

    asc_label_names = [
        id2label[label_id]
        for label_id in asc_label_ids
    ]

    report = classification_report(
        gold_labels,
        predicted_labels,
        labels=asc_label_ids,
        target_names=asc_label_names,
        digits=4,
        zero_division=0,
    )

    results_text = (
        f"Token accuracy (including O): {accuracy:.4f}\n\n"
        f"ASC classification report (excluding O):\n{report}"
    )

    print(results_text)

    output_dir = Path("evaluation_results")
    output_dir.mkdir(parents=True, exist_ok=True)

    (output_dir / "test_report.txt").write_text(
        results_text,
        encoding="utf-8",
    )
```

**Note.** `O` is excluded from the reported ASC categories, but its tokens remain in the evaluation arrays. Predicting an ASC label for an `O` token therefore still counts as a false positive.

## Run the evaluation

Save the file and run it from your terminal or command prompt:

```bash
python evaluate_tagger.py
```

The results will appear in the terminal and be saved to:

```text
evaluation_results/test_report.txt
```

## Interpret the results

Overall accuracy may be high because many tokens have the label `O`. Examine the per-category scores and **macro average F1** to assess performance across ASC categories.

Macro average F1 gives each ASC category equal weight. Weighted average F1 gives more weight to categories with more gold-standard examples.

These are **token-level classification scores**: they evaluate the ASC label assigned to each word, rather than the boundaries of multiword spans.

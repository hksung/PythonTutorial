## Part 3. Create frequency lists

Define a function that extracts lowercase tokens and lemmas while excluding spaces and punctuation:

```python
from collections import Counter


def get_frequencies(doc):
    tokens = [
        token.text.lower()
        for token in doc
        if not token.is_space and not token.is_punct
    ]

    lemmas = [
        token.lemma_.lower()
        for token in doc
        if not token.is_space and not token.is_punct
    ]

    return tokens, lemmas
```

Create frequency lists for both texts:

```python
tokens_a, lemmas_a = get_frequencies(doc_a)
tokens_b, lemmas_b = get_frequencies(doc_b)

frequencies = {
    "Text A tokens": Counter(tokens_a),
    "Text A lemmas": Counter(lemmas_a),
    "Text B tokens": Counter(tokens_b),
    "Text B lemmas": Counter(lemmas_b),
}
```

Report the size and vocabulary of each text:

```python
for label, frequency in frequencies.items():
    instances = sum(frequency.values())
    types = len(frequency)

    print(label)
    print("Instances:", instances)
    print("Types:", types)
    print()
```

## Part 4. Compare the frequency lists

Print the 20 most frequent tokens and lemmas in each text:

```python
for label, frequency in frequencies.items():
    print(label)
    print(frequency.most_common(20))
    print()
```

Because the texts may have different lengths, compare normalized frequencies as well as raw counts. The following function calculates occurrences per 1,000 text units:

```python
def normalized_frequency(frequency, total_units, number_of_units=1000):
    return {
        unit: count / total_units * number_of_units
        for unit, count in frequency.items()
    }


token_frequency_a = normalized_frequency(
    frequencies["Text A tokens"],
    len(tokens_a)
)

token_frequency_b = normalized_frequency(
    frequencies["Text B tokens"],
    len(tokens_b)
)

lemma_frequency_a = normalized_frequency(
    frequencies["Text A lemmas"],
    len(lemmas_a)
)

lemma_frequency_b = normalized_frequency(
    frequencies["Text B lemmas"],
    len(lemmas_b)
)
```

Compare selected units in both texts:

```python
units_to_compare = set(lemma_frequency_a) | set(lemma_frequency_b)

for lemma in sorted(units_to_compare):
    frequency_a = lemma_frequency_a.get(lemma, 0)
    frequency_b = lemma_frequency_b.get(lemma, 0)

    if frequency_a or frequency_b:
        print(
            lemma,
            round(frequency_a, 2),
            round(frequency_b, 2),
            sep="\t"
        )
```

You may focus this comparison on the most frequent units or on units that appear noticeably more often in one text than in the other.

## What is POS (part-of-speech) tagging?

POS tagging assigns a grammatical category to each word in a text. The assigned category is based not only on the form of the word but also on how the word is used in its sentence.

Consider the word *record*:

```text
They record every interview.
I listened to the record.
```

In the first sentence, *record* functions as a verb. In the second sentence, it functions as a noun. A part-of-speech tagger uses the surrounding context to predict the most likely analysis for each occurrence.

## Universal and language-specific tags

NLP pipelines often provide two levels of part-of-speech information.

### Universal part-of-speech tags

Universal POS tags, usually called **UPOS tags**, provide a relatively small set of categories that can be applied across languages.

Examples include:

| UPOS tag | General category | Example |
|---|---|---|
| `NOUN` | common noun | *student* |
| `PROPN` | proper noun | *Hawaiʻi* |
| `VERB` | lexical verb | *analyze* |
| `AUX` | auxiliary | *have* in *have written* |
| `ADJ` | adjective | *complex* |
| `ADV` | adverb | *carefully* |
| `PRON` | pronoun | *they* |
| `DET` | determiner | *the* |
| `ADP` | adposition | *in* |
| `CCONJ` | coordinating conjunction | *and* |
| `SCONJ` | subordinating conjunction | *because* |
| `PART` | particle | language-dependent |
| `PUNCT` | punctuation | `.` |

Because UPOS categories are shared across languages, they are useful for creating a common computational workflow.

However, the same UPOS label does not guarantee that two languages have identical grammatical systems or annotation conventions. Cross-linguistic comparisons still require careful interpretation.

### Language-specific part-of-speech tags

A language-specific tag (XPOS) provides a more detailed analysis based on a particular annotation scheme or treebank.

For English, a verb might receive a detailed tag such as:

```text
VB   base-form verb
VBD  past-tense verb
VBG  gerund or present participle
VBN  past participle
```

For Korean, a detailed analysis may identify categories such as common nouns, particles, connective endings, and sentence-final endings. Depending on the model and tokenization scheme, multiple Korean-specific tags may appear together in one analysis.

In this tutorial:

- spaCy's `token.pos_` provides a universal part-of-speech category;
- spaCy's `token.tag_` provides a more detailed English tag;
- Stanza's `word.upos` provides a universal part-of-speech category;
- Stanza's `word.xpos` provides a treebank-specific Korean tag.

## Why use different libraries?

We will use:

- **spaCy** for English;
- **Stanza** for Korean.

This choice allows us to practice working with two widely used NLP libraries and to examine how different libraries organize linguistic annotations.
The two libraries use different Python objects:

| Information | spaCy | Stanza |
|---|---|---|
| Full processed text | `Doc` | `Document` |
| Sentence | `Span` | `Sentence` |
| Word-level object | `Token` | `Word` |
| Original form | `token.text` | `word.text` |
| Lemma | `token.lemma_` | `word.lemma` |
| Universal POS | `token.pos_` | `word.upos` |
| Detailed POS | `token.tag_` | `word.xpos` |
| Morphological features | `token.morph` | `word.feats` |

Although the attribute names differ, we can convert both outputs into the same record format later in the tutorial.

## From POS tagging to lexical diversity

Lexical diversity concerns variation in the lexical items used in a text. Before calculating it, we must make several decisions:

1. What counts as a token?
2. Should inflected forms be combined under a lemma?
3. Should function words be included?
4. Should proper nouns be included?
5. Which diversity measure is appropriate for the text length?

POS tagging helps with the third and fourth decisions.

A common operational definition treats the following UPOS categories as lexical words:

```python
LEXICAL_POS = {
    "NOUN",
    "VERB",
    "ADJ",
    "ADV"
}
```

This is a useful starting point, not a universal rule. A research project must explain and justify its inclusion criteria. For example, researchers may disagree about whether to include:

- proper nouns (`PROPN`);
- auxiliary verbs (`AUX`);
- numerals (`NUM`);

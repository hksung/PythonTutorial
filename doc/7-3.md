# Korean POS tagging with Stanza

In this tutorial, we will use Stanza to tokenize, tag, and lemmatize Korean text. We will also examine how Stanza organizes its output into documents, sentences, tokens, and words.

`Stanza` is a Python NLP toolkit developed by the Stanford NLP Group. It provides pretrained language-specific pipelines for tasks such as tokenization, POS tagging, morphological analysis, lemmatization, and dependency parsing. The language model and training package used by the pipeline can be specified when the pipeline is created.

Although spaCy also supports Korean, we use Stanza in this tutorial to gain experience with a different Korean NLP pipeline and annotation scheme. Korean NLP resources do not all use the same language-specific POS tag set. In my previous research, I have primarily used POS annotations based on the [Sejong tag set](https://nlpxl2korean.github.io/UD-KSL/xpos/) for fine-grained morphosyntactic applications, so here we practice using a pipeline and annotation scheme—Stanza with Korean GSD (which supports Sejong tag set).

Korean requires particular care because a space-delimited unit can contain a lexical stem together with one or more grammatical elements. The tokenization and annotation scheme therefore influence what will later count as a lexical item.

## Installing Stanza

Install Stanza from a terminal or command prompt:

```bash
pip install -U stanza
```

Import Stanza and download the Korean GSD models required for tokenization, POS tagging, and lemmatization:

```python
import stanza

stanza.download(
    "ko",
    package="gsd",
    processors="tokenize,pos,lemma"
)
```

## Building a Korean pipeline

Create a Korean pipeline using the same GSD package and the three downloaded processors:

```python
nlp_ko = stanza.Pipeline(
    lang="ko",
    package="gsd",
    processors="tokenize,pos,lemma",
    use_gpu=False
)
```

The pipeline includes three processors:

* `tokenize` identifies sentences and tokens;
* `pos` assigns universal and language-specific POS tags, as well as morphological features;
* `lemma` assigns a normalized lemma to each word.


## Processing a Korean sentence

Create a Korean text:

```python
korean_text = "학생들은 과제를 매우 꼼꼼하게 작성했습니다."
```

Process the text:

```python
korean_doc = nlp_ko(korean_text)
```

The result is a Stanza `Document`:

```python
print(type(korean_doc))
```

A `Document` contains one or more `Sentence` objects:

```python
for sentence in korean_doc.sentences:
    print(type(sentence))
    print(sentence.text)
```

## Understanding Stanza's data structure

Stanza organizes linguistic annotations hierarchically:

```text
Document
└── Sentence
    ├── Token
    │   └── Word
    ├── Token
    │   └── Word
    └── ...
```

A Stanza `Token` represents a token in the tokenized text. A `Word` represents the syntactic word used by downstream annotation components.

In languages with multi-word-token expansion, one `Token` may contain multiple `Word` objects. The Korean model's behavior depends on its tokenization and treebank conventions, so the actual output should be inspected rather than assumed.

Print token-level information:

```python
for sentence in korean_doc.sentences:
    for token in sentence.tokens:
        print(
            "Token text:", token.text,
            "| Token ID:", token.id,
            "| Number of words:", len(token.words)
        )
```

Then print word-level information:

```python
for sentence in korean_doc.sentences:
    for word in sentence.words:
        print(
            "Word text:", word.text,
            "| Word ID:", word.id
        )
```

The POS and lemma annotations used in this tutorial are stored on `Word` objects.

## Inspecting Korean annotations

Print the main annotations:

```python
for sentence in korean_doc.sentences:
    for word in sentence.words:
        print(
            word.text,
            word.lemma,
            word.upos,
            word.xpos,
            word.feats,
            sep="\t"
        )
```

The attributes can be interpreted as follows:

- `word.text`: the form represented by the Stanza `Word`;
- `word.lemma`: the lemma assigned by the lemmatizer;
- `word.upos`: the Universal POS category;
- `word.xpos`: the treebank-specific POS analysis;
- `word.feats`: Universal Dependencies morphological features, when available.

Because model packages and annotation conventions can change, inspect the actual output produced in your environment.

## Printing a readable analysis table

Use formatted output:

```python
print(
    f"{'WORD':<20}"
    f"{'LEMMA':<25}"
    f"{'UPOS':<10}"
    f"{'XPOS':<20}"
    f"{'FEATURES'}"
)

for sentence in korean_doc.sentences:
    for word in sentence.words:
        lemma = word.lemma or "_"
        upos = word.upos or "_"
        xpos = word.xpos or "_"
        feats = word.feats or "_"

        print(
            f"{word.text:<20}"
            f"{lemma:<25}"
            f"{upos:<10}"
            f"{xpos:<20}"
            f"{feats}"
        )
```

When `word.xpos` contains more than one tag joined by a symbol such as `+`, it indicates that the model represents multiple internal grammatical elements in the detailed analysis.

## Korean space-delimited units and morphemes

A Korean space-delimited unit may contain several grammatical elements.

For example, the form:

```text
학생들은
```

can be analyzed linguistically as containing elements corresponding approximately to:

```text
학생 + 들 + 은
student + plural + topic
```

A complex predicate may contain a lexical stem together with tense, aspect, honorific, connective, auxiliary, or sentence-ending material.

However, do not assume that Stanza creates one separate `Word` object for every morpheme. Its output follows the tokenization and annotation conventions of the model's training data.

Therefore, avoid assuming that:

```text
one space-delimited unit = one lexical word
one Stanza Token        = one morpheme
one Stanza Word         = one morpheme
```

The token, word, lemma, UPOS tag, and XPOS tag should be inspected together.

## Comparing tokens and words directly

The following code prints each token and its associated words:

```python
for sentence in korean_doc.sentences:
    for token in sentence.tokens:
        print("TOKEN:", token.text)

        for word in token.words:
            print(
                "   WORD:", word.text,
                "| LEMMA:", word.lemma,
                "| UPOS:", word.upos,
                "| XPOS:", word.xpos
            )
```

This display helps reveal whether the pipeline maps one token to one word or creates a more complex structure.

## Excluding punctuation

Unlike spaCy tokens, Stanza `Word` objects do not provide `is_punct`. We can use the UPOS tag:

```python
for sentence in korean_doc.sentences:
    for word in sentence.words:
        if word.upos != "PUNCT":
            print(word.text, word.upos)
```

This keeps all non-punctuation words, including both lexical and grammatical categories.

## Extracting Korean nouns

Extract common-noun lemmas:

```python
korean_nouns = [
    (word.lemma or word.text).lower()
    for sentence in korean_doc.sentences
    for word in sentence.words
    if word.upos == "NOUN"
]

print(korean_nouns)
```

To include proper nouns:

```python
korean_nouns_and_names = [
    (word.lemma or word.text).lower()
    for sentence in korean_doc.sentences
    for word in sentence.words
    if word.upos in {"NOUN", "PROPN"}
]

print(korean_nouns_and_names)
```

The expression:

```python
word.lemma or word.text
```

uses the original word form as a fallback if no lemma is available.

## Extracting Korean verbs

Extract lexical verbs:

```python
korean_verbs = [
    (word.lemma or word.text).lower()
    for sentence in korean_doc.sentences
    for word in sentence.words
    if word.upos == "VERB"
]

print(korean_verbs)
```

Extract auxiliaries separately:

```python
korean_auxiliaries = [
    (word.lemma or word.text).lower()
    for sentence in korean_doc.sentences
    for word in sentence.words
    if word.upos == "AUX"
]

print(korean_auxiliaries)
```

Whether the model distinguishes a particular predicate as `VERB` or `AUX` depends on its annotation scheme and analysis of the context.

## Counting Korean POS categories

Use `Counter` to calculate UPOS frequencies:

```python
from collections import Counter

korean_pos_counts = Counter(
    word.upos
    for sentence in korean_doc.sentences
    for word in sentence.words
    if word.upos != "PUNCT"
)

print(korean_pos_counts)
```

Display categories from most to least frequent:

```python
for pos, frequency in korean_pos_counts.most_common():
    print(pos, frequency)
```

## Creating a reusable inspection function

Define a function for Korean text:

```python
def inspect_stanza_text(text, nlp):
    doc = nlp(text)

    print(
        f"{'WORD':<20}"
        f"{'LEMMA':<25}"
        f"{'UPOS':<10}"
        f"{'XPOS':<20}"
        f"{'FEATURES'}"
    )

    for sentence in doc.sentences:
        for word in sentence.words:
            lemma = word.lemma or "_"
            upos = word.upos or "_"
            xpos = word.xpos or "_"
            feats = word.feats or "_"

            print(
                f"{word.text:<20}"
                f"{lemma:<25}"
                f"{upos:<10}"
                f"{xpos:<20}"
                f"{feats}"
            )

    return doc
```

Apply the function:

```python
new_korean_doc = inspect_stanza_text(
    "학습자들은 다양한 표현을 사용했습니다.",
    nlp_ko
)
```

## Inspecting a more complex predicate

Process a sentence containing a complex verb expression:

```python
complex_text = "학생들은 과제를 작성하고 있었습니다."
complex_doc = nlp_ko(complex_text)

for sentence in complex_doc.sentences:

                "\nXPOS:", word.xpos,
                "\nFeatures:", word.feats,
                "\n"
            )
```
